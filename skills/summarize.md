name: summarize
description: Summarize the current Scope, or a Source or topic you name.
usage: /summarize [source name or topic]
---
Write a clear, faithful summary of the numbered passages. Lead with the main point, then the
key facts, figures and names. Cite the passages you rely on like [1] or [2]. If a passage is
marked as the primary Source, centre the summary on it and use the other passages only as
supporting references. Use only what the passages say: no outside knowledge, no invented numbers.
